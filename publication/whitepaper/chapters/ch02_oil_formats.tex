\section{Design Principles}
\label{sec:format_design_principles}

The OIL format system is governed by four inviolable design principles.
These are provable constraints that \texttt{FormatRegistry} enforces.
Every format from OIL1 through OIL32 must satisfy all four.

\subsection{Principle~1: Trainability}

Every format must support end-to-end differentiable training via the
Straight-Through Estimator (STE). The forward quantized index
$i_j = \argmin_k |w_j - c_k|$ is piecewise-constant with zero
gradient almost everywhere; the backward pass bypasses this via
$\partial L / \partial \tilde{w}_j \stackrel{\text{STE}}{\approx}
\partial L / \partial w_j$, treating quantization as the identity.
Codebooks $\{c_k\}$ update via EMA: $c_k^{(t+1)} = (1 - \alpha) c_k^{(t)}
+ \alpha \cdot \bar{w}_k^{(t)}$, where $\bar{w}_k^{(t)}$ is the mean of
weights assigned to centroid $k$ at step $t$. Training convergence
requires the STE gradient variance to be bounded:
$\mathrm{Var}[\nabla_{\tilde{w}} L] \leq C \cdot
\mathrm{Var}[\nabla_w L]$ for format-dependent constant $C$.
Standard SGD convergence in $O(1/\epsilon)$ iterations holds when
$\eta \in (0, 2/L)$ where $L$ is the loss smoothness constant.

\subsection{Principle~2: Losslessness Where Achievable}

When codebook size $K$ equals or exceeds sub-block size $G$, the
quantization mapping is injective: every input vector
$\mathbf{w} \in \mathbb{R}^G$ maps to a unique index assignment
$\mathbf{i} \in \{0,\ldots,K-1\}^G$, and dequantization recovers
$\mathbf{w}$ exactly. Formally, the composition of quantization and
dequantization is the identity: $Q^{-1}(Q(\mathbf{w})) = \mathbf{w}$
for all $\mathbf{w}$ when $K \geq G$. GRP variants with sub-blocks of
size $G \leq K$ exploit this for provably zero MSE (e.g., OIL16\_GRP
with $K=256$, $G=8$ is injective and lossless). Formats where
$K < G$ are honestly lossy (e.g., OIL2\_GRP with $K=4$, $G=128$);
the registry maintains this distinction rigorously in the
\texttt{lossless} field.

\subsection{Principle~3: Progressive Degradation}

Distortion $D(f) = \mathbb{E}[(w - \hat{w}_f)^2]$ must be
monotonically non-decreasing as BPW decreases. Each format is a
representational superset of the next: OIL32 stores FP32, OIL16 stores
FP16, OIL8 uses 256 centroids, continuing to OIL1's single block mean.
Inter-format ratios satisfy $D(f_k) / D(f_{k+1}) \leq \beta < 4$,
preventing catastrophic transitions.

\subsection{Principle~4: Cross-BPW Superiority}

OIL at $X$~BPW beats industrial formats at $2X$~BPW. Lloyd-Max
centroids occupy conditional expectations of quantization bins, not
geometric midpoints. For Gaussian weights, Lloyd-Max variance is
$\sigma_Q^2 \approx 0.363 \cdot \Delta^2 / 12$ versus uniform's
$\Delta^2/12$, a $2.75\times$ advantage that compounds with block-level
scale adaptation.

\subsection{GRP Variants}

All base formats have GRP (lossless block-grouped) variants that add per-group scale/zp:
OIL1\_GRP, OIL2\_GRP, OIL4\_GRP, OIL8\_GRP, OIL16\_GRP, SPARK\_Q0\_GRP, SPARK\_SPARSE\_GRP.
GRP variants use the same BPW as their base but apply separate scale and zero-point
per group block, enabling lossless reconstruction when $K \geq G$.

\subsection{OIL1 (1.0 BPW)}

OIL1 replaces each 32-element block with its mean:
$\hat{w}_j = \bar{w}_B$. Storage: one FP32 centroid per 32 weights
(1.0~BPW). MSE $= 2.50 \times 10^{-1}$. The single Lloyd-Max centroid
is the arithmetic mean, minimizing block MSE.

\subsection{OIL2 (2.0 BPW)}

A 2-bit index into a 4-entry Lloyd-Max codebook:
$i_j = \argmin_k |w_j - c_k|$, $\hat{w}_j = c_{i_j}$. The codebook is
trained via 20 Lloyd-Max iterations: assign each weight to its nearest
centroid, then set each centroid to the mean of its assigned weights.
Storage: 16\,MB for 64M params. MSE $= 1.18 \times 10^{-1}$, a
$2.1\times$ improvement over OIL1.

\subsection{OIL4 (4.0 BPW)}

A 4-bit nibble index into a 16-entry FP16 codebook. Two weights per
byte yield 32\,MB for 64M params. MSE $= 9.40 \times 10^{-3}$,
$12.5\times$ better than OIL2. OIL4 beats Q4\_0 (uniform 4-bit) by
$2.1\times$ in MSE at identical bit-width.

\subsection{OIL8 (8.0 BPW)}

An 8-bit index into a 256-entry FP32 codebook. One byte per weight,
64\,MB for 64M params. MSE $= 3.12 \times 10^{-5}$. OIL8 serves as
the upper tier in CID mixed-precision assignments. Its quantization
error falls below the FP16 noise floor.

\subsection{OIL16 (16.0 BPW)}

IEEE 754 FP16 storage: 128\,MB for 64M params.
MSE $= 9.77 \times 10^{-4}$ from mantissa truncation only,
effectively lossless for most distributions. Receives the top
$p$-percentile most CID-sensitive weights.

\subsection{OIL32 (32.0 BPW)}

FP32 identity via \texttt{memcpy}: zero quantization, zero loss, zero
codebook. 256\,MB for 64M params. Serves as SOPS normalization
reference and the format for the $0.01\%$ most critical weights.
Quantization variance is exactly zero.

\section{Lossless GRP Variants}
\label{sec:grp_variants}

GRP partitions each weight block into sub-blocks of size $G$, each
with its own scale $s_g$ and zero point $z_g$. When $K \geq G$, the
mapping is injective and reconstruction is exact.

\subsection{OIL2\_GRP (2.0 BPW)}

Per-group scale/zp with $K=4$ centroids adapts to local weight
distribution within each 128-weight group. MSE $= 5.90 \times 10^{-2}$
($2.0\times$ improvement over OIL2). Storage: 16\,MB $\;+\;$ 4~MB
overhead for group metadata at $G=128$.

\subsection{OIL4\_GRP (4.0 BPW)}

\begin{mythm}[OIL4\_GRP Quality Advantage]{thm:oil4_grp_advantage}
For weight blocks with intra-group variance $\sigma_g^2$, OIL4\_GRP
reduces quantization variance by $(\sigma_w / \sigma_g)^2$ versus
OIL4. This ratio exceeds $4.0$ for trained weights, guaranteeing at
least a $4\times$ quality improvement from grouping.
\end{mythm}

Each group of 128 weights is normalized to $[0,1]$ via
$s_g = \max(w) - \min(w)$, $z_g = \min(w)$ before Lloyd-Max
quantization with 16 centroids. MSE $= 4.70 \times 10^{-3}$.

\subsection{OIL8\_GRP (8.0 BPW)}

Per-group normalization with $K=256$ centroids. Although $K > G$, the
codebook is shared across groups (trained globally), so reconstruction
is not exact. Per-group normalization reduces dynamic range, yielding
MSE $= 1.56 \times 10^{-5}$---a $2.0\times$ improvement over OIL8.

\begin{mythm}[GRP Storage Formula]{thm:grp_storage}
For $N$ weights, group size $G$, index width $W$ bits, 8-byte group
overhead: $\mathrm{bytes} = N \cdot W / 8 + (N / G) \cdot 8$.
OIL4\_GRP with $N=64\times10^6$, $G=128$, $W=4$:
$32\text{M} + 4\text{M} = 36\text{MB}$.
\end{mythm}

Two sources drive this advantage. First, Lloyd-Max centroids minimize
MSE for the actual distribution by placing bin boundaries at
distribution quantiles, not uniform intervals. Second, per-block

MSE advantage that compounds with CID-weighted mixed precision
(Chapter~\ref{ch:mixed_precision}).

\section{The Quantization Barrier Theorem}
\label{sec:quantization_barrier}

The nearest-neighbor index assignment creates a dead zone around each
codebook entry that blocks small gradient updates from changing any
parameter. This converts continuous SGD into a discrete-continuous
hybrid system.

\begin{mythm}[Quantization Barrier]{thm:quant_barrier}
Let $w_j = s_b \cdot c(i_j)$ be a quantized weight with block scale
$s_b$, codebook entry $c(i_j)$, and learning rate $\eta$. The gradient
update $g_j = \partial L / \partial w_j$ fails to change the index
$i_j$ when $|\eta \cdot g_j| < s_b \cdot \Delta_{\min} / 2$, where
$\Delta_{\min} = \min_{k \neq k'} |c(k) - c(k')|$ is the minimum
codebook gap. For Ternary weights with $\Delta_{\min} = 1$, the dead
zone has width $s_b$. For OIL8 with $K = 256$ centroids spanning
$[-3\sigma_w, 3\sigma_w]$, the dead zone width is
$s_b \cdot \sigma_w / 42.7$.
\end{mythm}

\begin{proof}
The virtual continuous update $\tilde{w}_j = w_j - \eta \cdot g_j$ lies
at distance $|\eta \cdot g_j|$ from $c(i_j)$. The nearest alternative
$c(k^*)$ satisfies $|c(i_j) - c(k^*)| \geq \Delta_{\min}$, so its
distance from $\tilde{w}_j$ is at least
$s_b \cdot \Delta_{\min} - |\eta \cdot g_j|$. The index is unchanged
when $|\eta \cdot g_j| < s_b \cdot \Delta_{\min} / 2$. For OIL8,
$\Delta_{\min} = 6\sigma_w / 255 \approx 0.0235\sigma_w$, giving
dead zone $s_b \cdot 0.0118\sigma_w$. \qed
\end{proof}

\begin{mythm}[Dead Zone as Implicit Regularization]{thm:dead_zone_reg}
The dead zone suppresses gradient noise
$|\eta \cdot g_j| < s_b \cdot \Delta_{\min} / 2$ with probability
$1 - \delta$, where $\delta = \Pr[|\xi_j| \geq
s_b \cdot \Delta_{\min} / (2\eta)]$ for SGD noise $\xi_j$. This is
implicit $L_0$ regularization, penalizing updates lacking sufficient
signal magnitude.
\end{mythm}

The dead zone eliminates the long tail of small-magnitude gradient
noise that accumulates in FP32 training, creating natural sparsity in
update space. Quantitatively, for a gradient with noise variance
$\sigma_\xi^2$, the fraction of updates blocked is
$\Phi\bigl(s_b \cdot \Delta_{\min} / (2\eta\sigma_\xi)\bigr)$ where
$\Phi$ is the Gaussian CDF. At $\eta = 10^{-4}$ and $s_b = 1$ with
OIL8 ($\Delta_{\min} \approx 0.0235\sigma_w$), approximately 40\% of
gradient updates land in the dead zone. This yields 5--10$\times$
tighter algorithmic stability bounds than FP32 SGD, analyzed in
Chapter~\ref{ch:native_training}.

\section{Information Weight Analysis}
\label{sec:iw_analysis}

Information Weight is $\IW = 32 / \BPW$: the number of FP32-equivalent
elements a single quantized weight represents. At 4~BPW, $\IW = 8$:
each such weight carries the information capacity of 8 FP32 weights in
the same bit budget.

\begin{mythm}[Information Weight Conservation]{thm:iw_conservation}
For every OIL format, $\IW \times \text{bytes\_per\_weight} = 4$.
Every byte of weight memory yields exactly 4 FP32-equivalent
operations regardless of format.
\end{mythm}

\begin{proof}
$\IW = 32 / \BPW$, bytes per weight $= \BPW / 8$.
Product: $(32 / \BPW) \times (\BPW / 8) = 4$. \qed
\end{proof}

The Information Weight also determines the SOPS contribution of each
format. A 64M-parameter model at uniform OIL4 stores 64M $\times\, 8 =
512$M information-weight units in its 32~MB budget. At uniform OIL8,
the same budget stores only 256M information-weight units---half the
information-processing capacity for the same memory footprint. The
SOPS metric (Chapter~\ref{ch:sops}) captures this directly: SOPS =
$N \cdot \IW \cdot f_{\text{ops}}$, where $f_{\text{ops}}$ is
the operation frequency. Compression never destroys information
capacity---it redistributes it. A model at 4~BPW with $\IW = 8$
performs $8\times$ more weight-value interactions per memory
bandwidth unit versus FP32.

\subsection{Future Format Extensions}

The OIL format architecture is designed for extensibility. The 25 currently registered formats occupy format IDs 0--24 in the registry, leaving IDs 25--63 reserved for future extensions. Candidate extensions under consideration include variable-BPW formats where each layer selects its own BPW based on sensitivity analysis, hierarchical formats with multiple codebooks per layer for mixture-of-experts routing, and temporal formats with BPW varying over training steps. The registry mechanism ensures backward compatibility: any format registered at ID $k$ is immutable once published, guaranteeing that models quantized today remain decodable by future implementations regardless of format extensions.

This forward-looking design positions OIL as both a practical quantization system for current hardware and a research platform for next-generation mixed-precision training algorithms.
